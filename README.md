# UR7e 打印实验汇报与最小共享代码

[打开完整汇报](https://blue-autumn.github.io/ur7e-print-study/) · [运行最小共享样例](https://blue-autumn.github.io/ur7e-print-study/starter/viewer.html) · [下载独立 starter.zip](https://blue-autumn.github.io/ur7e-print-study/starter.zip)

要修改机械臂参数并测算其他六轴机械臂，从 [starter/README.md](starter/README.md) 开始。该目录可独立运行，含 UR7e 名义样例、参数化 DH 正运动学、小型数值位置求解入口、轨迹导入和三维播放。给自己的 AI 阅读 [starter/AGENTS.md](starter/AGENTS.md)，再提供具体型号、运动学、限位及 TCP 资料。

公开汇报的结果属于各自记录的机器人和条件。新型号需要重新计算。共享样例显示运动学骨架，内置小计算约束 XYZ，工具朝向自由，碰撞未检查。
