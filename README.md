# UR7e 打印实验汇报与最小共享代码

[打开完整汇报](https://blue-autumn.github.io/ur7e-print-study/) · [运行最小共享样例](https://blue-autumn.github.io/ur7e-print-study/starter/viewer.html) · [下载独立 starter.zip](https://blue-autumn.github.io/ur7e-print-study/starter.zip)

要修改机械臂参数并测算其他六轴机械臂，从 [starter/README.md](starter/README.md) 开始。独立查看页提供左侧连杆三维模型、右侧多方案按钮及结果表、关节驱动和轨迹播放。附三个 UR7e 打印回放、可复算的短直线、通用 DH 正运动学、结果导入、STL 连杆模型打包和方案清单生成。给自己的 AI 阅读 [starter/AGENTS.md](starter/AGENTS.md)，再提供具体型号、运动学、限位及 TCP 资料。

公开汇报的结果属于各自记录的机器人和条件。新型号需要重新计算并接入匹配外形；外形未提供时显示骨架。内置小计算约束 XYZ，工具朝向自由，碰撞未检查。
