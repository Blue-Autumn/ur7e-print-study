曲面法向采样实验

这个工件是人为定义的数学曲面，没有使用实物扫描。示例采用 200 × 200 mm 床、地装机器人、水平间距 650 mm、床面中心低于机器人安装中心 650 mm 的已存工况 robot_column_d650_r660。TCP 取 2026-09-21 历史 RTDE 定义。曲面局部系与名义热床系重合。

双击 曲面法向与姿态命中 可离线旋转工件，点选近处样点并查看各个姿态的关节角。所选点的全部姿态可导出 CSV。

曲面的投影为 168 × 128 mm。以毫米代入公式 z = 12 + 0.0018x² + 0.00055y² + 0.00115xy，取 9 × 7 个顶点，每个矩形拆为两个三角形。以下面积与法向均属于这 96 个三角形。面积合计 21,892.28 mm²。

每个三角面依据最长边和面积进行等面积细分，每个小三角形取一个重心。12 mm 边长上限和 64 mm² 面积上限产生了 864 个点。实际小格最长边为 10.51 mm。正法线由三角形顶点的右手绕序决定。零倾角时喷嘴 +Z 沿负法线指向材料，工具 +X 取曲面坐标 +X 在切平面上的投影。两者近乎平行时改用曲面 +Y 的投影。正方位角从这条切线朝 法线 × 切线 转，正滚转绕倾斜后的工具 +Z 旋转。

床面曲面任务 名义 IK 命中
垂直于各自局部面，滚转 0° 581 / 864 点
垂直于各自局部面，滚转 90° 864 / 864 点
每点 50 个姿态合计 30,658 / 43,200
每点至少一个姿态命中 864 / 864 点
每点全部 50 个姿态命中 0 / 864 点

50 个姿态由 0°、10°、20°、30° 倾角和 0°、90° 滚转组成。非零倾角各取 8 个方位。按面积加权的姿态命中率为 70.97%。每个命中保存了一个关节见证。正运动学回代见证的最大位置误差为 1.17 × 10⁻¹² mm，最大姿态误差为 1.08 × 10⁻¹³°。这份实验核对了孤立位置和姿态的运动学逆解。现场配准、工件碰撞、连续沉积路径与成形质量均待验证。

文件

文件 内容
synthetic_surface.npz 示例的顶点 vertices_mm 与三角形 faces
surface_points.ply 桌面世界系点云，单位 mm，含 nx/ny/nz、颜色、命中数、分母和代表面积。色彩从砖红渐变至青绿，命中越多越接近青绿。可用 CloudCompare 等 PLY 查看器打开
samples.npz 逐点曲面重心坐标、原面编号、局部和世界点、积分面积、全姿态命中、逐命中关节角和关节分支编号
summary.json 曲面来源、单位、矩阵、各姿态命中与加权面积比例、源代码和数据摘要

samples.npz 中，点序号为 i，姿态序号为 j。读取 nominal_reachable[i,j] 和 witness_q_rad[i,j,:] 可取判定与六个名义关节角，角度单位为弧度。世界目标位置为 world_xyz_mm[i,:]，目标旋转矩阵为 face_R_world[face_index[i],j,:,:]。angles_deg[j,:] 给出倾角、方位和滚转。未找到的关节见证取 NaN。raw_ik_slots[i,j] 统计 8 个解析槽中返回有效角度的个数，奇异处可能有多个槽返回同一解。

复跑或替换曲面

在项目根目录运行。

python -m lab.surface_tasks --demo --out results/surface_normals
python -m lab.surface_tasks --input workpiece.stl --stl-unit mm --source-label "工件设计网格" --bed-T-surface bed_T_surface.json --case robot_column_d450_r360 --spacing-mm 8 --max-area-mm2 32 --out results/custom_surface

本地 STL 同时支持 ASCII 和二进制。STL 不记录长度单位，调用时填写 mm、cm、m 或 inch。也可传入包含毫米顶点和零起始三角索引的 NPZ。程序以顶点绕序重新计算面法线，--flip-normals 可全局反转。局部面绕序有冲突时请查看 summary.json 中的 edge_winding。要改变倾角、方位或滚转，分别用 --tilts、--azimuths、--rolls 指定角度列表。

bed_T_surface.json 存放 4 × 4 刚体矩阵，把曲面局部坐标映到热床坐标。矩阵平移用米。未指定时会按两系重合的假设计算并记录。在拿到现场工件定位与机器人基座测量前，结果对应输入的名义布局。
